# SetPlay — Unit & Integration Tests

Place Vitest unit and integration tests in this directory.

## Conventions

- Files must end in `.test.ts` or `.spec.ts`
- Group by the module being tested, e.g.:
  - `stream-matcher.test.ts` — tests for the stream-to-tournament matching logic
  - `db-events.test.ts` — tests for D1 event CRUD operations
